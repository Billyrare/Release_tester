# 🔏 Операции нанесения маркировки (Marking Operations)

Данный документ описывает использование новых операций нанесения маркировки для потребительской упаковки (КИ) и групповой упаковки (КИГУ).

## 📋 Обзор

Реализованы два типа операций нанесения:

### 1. **Нанесение КИ (Unit Packaging)**
- **Endpoint**: `POST /v1/operations/apply-marking-ki`
- **Назначение**: Нанесение маркировки на потребительскую упаковку товара
- **Используется для**: Отдельных товарных единиц
- **Тип упаковки (cisType)**: `UNIT`

### 2. **Нанесение КИГУ (Group Packaging)**
- **Endpoint**: `POST /v1/operations/apply-marking-kigu`
- **Назначение**: Нанесение маркировки на групповую упаковку (например, упаковка из нескольких единиц)
- **Используется для**: Упаковок товаров (как пиво в ящике)
- **Тип упаковки (cisType)**: `GROUP`

## 🔧 API Структура

### Запрос

Оба эндпоинта принимают одинаковую структуру запроса:

```json
{
  "orderId": "uuid",              // ID заказа (обязательный)
  "gtin": "string",               // GTIN товара (обязательный)
  "quantity": 1,                  // Количество кодов для нанесения (опционально, по умолчанию 1)
  "productGroup": "water",        // Товарная группа (обязательный)
  "businessPlaceId": 1,           // ID места деятельности (опционально, по умолчанию 1)
  "releaseType": "PRODUCTION",    // Способ ввода в оборот: PRODUCTION, IMPORT, TAKE_OVER
  "manufacturerCountry": "UZ"     // Код страны (опционально, по умолчанию UZ)
}
```

### Ответ при успехе

```json
{
  "status": "applied",                          // Статус нанесения
  "reportId": "uuid",                           // ID отчета в API
  "codesApplied": 1,                            // Количество нанесенных кодов
  "releaseType": "PRODUCTION",                  // Способ ввода
  "cisType": "UNIT",                            // Тип упаковки (UNIT или GROUP)
  "productGroup": "water",                      // Товарная группа
  "shortCodes": ["0103077972920077TestCode1"]  // Укороченные коды в формате КИ
}
```

## 🔐 Формат кодов

Система автоматически обрезает полные коды маркировки (КМ) до формата КИ (Кода Идентификации):

- **КМ (Полный код)**: содержит все данные + криптохвост (часть после GS character)
- **КИ (Укороченный код)**: содержит только основные идентификационные данные, обрезан до указанной длины

**Пример обрезания для товарной группы `water` (КИ=31)**:
```
КМ: 0103077972920077TestCode1UehUxxxxxxxx (полный код)
КИ: 0103077972920077TestCode1UehU (31 символ)
```

## 🎯 Использование через UI

1. Откройте вкладку **"🔏 Нанесение"** в веб-интерфейсе
2. Заполните форму:
   - **Order ID**: скопируйте ID из ранее созданного заказа
   - **GTIN**: укажите GTIN товара из заказа
   - **Группа товара**: выберите товарную группу
   - **Количество кодов**: сколько кодов нанести
   - **BusinessPlaceId**: ID места деятельности (по умолчанию 1)
   - **Способ ввода (releaseType)**: выберите PRODUCTION, IMPORT или TAKE_OVER
   - **Страна производства**: введите код страны (по умолчанию UZ)
   - **Тип упаковки**: выберите КИ или КИГУ

3. Нажмите соответствующую кнопку:
   - **"📌 Нанесение КИ"** - для потребительской упаковки
   - **"📦 Нанесение КИГУ"** - для групповой упаковки

4. Результат отобразится в панели результатов

## ⚙️ Технические деталии

### Процесс обработки

1. **Валидация входных данных**:
   - Проверка наличия обязательных полей (orderId, gtin, productGroup)
   - Установка значений по умолчанию для опциональных полей

2. **Выгрузка кодов из заказа**:
   - Используется метод `markingService.GetCodes()` для получения кодов из заказа
   - Получение полных кодов маркировки (КМ) с разделителем GS

3. **Обрезание кодов до формата КИ**:
   - Используется функция `util.TruncateToKIList()` 
   - Коды обрезаются до точной длины для товарной группы
   - Удаляются GS-разделители (0x1D)

4. **Отправка отчета о нанесении**:
   - Используется метод `markingService.ReportUtilisation()`
   - Отправка укороченных кодов на API маркировки
   - Установка дат производства и истечения

5. **Возврат результата**:
   - Status: "applied"
   - Report ID от API
   - Информация о нанесенных кодах

### Обработка ошибок

- **400**: Неверные входные данные (missing orderId, gtin, productGroup)
- **500**: Ошибка при выгрузке кодов или отправке отчета
