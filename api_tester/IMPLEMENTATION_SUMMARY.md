# 🤖 Автоматизированная система тестирования API ASL BELGISI

## ✅ Что было реализовано

### 1. **Система логирования тестов в БД** ✓
- **Таблица `test_runs`**: информация о каждом запуске набора тестов
  - `id`, `suite_name`, `status`, `total_cases`, `passed_cases`, `failed_cases`, `skipped_cases`
  - `started_at`, `completed_at`, `duration_seconds`, `error_message`

- **Таблица `test_cases`**: детальные результаты каждого тестового сценария
  - `id`, `run_id`, `case_name`, `description`, `status`
  - `request_body`, `response_body`, `error_message`, `duration_milliseconds`

- **Функции в `internal/db/db.go`**:
  - `StartTestRun()` - начало запуска набора тестов
  - `LogTestCase()` - логирование результата одного теста
  - `UpdateTestRunStats()` - обновление статистики
  - `GetTestRunHistory()` - получение истории запусков
  - `GetTestCasesByRunID()` - получение деталей конкретного запуска

### 2. **Backend endpoints для тестирования** ✓

#### Orders Suite (Заказы)
```
POST /v1/test/orders-suite
```
**8+ сценариев**:
- `order_water_free` - заказ воды (бесплатная ТГ)
- `order_tobacco_paid` - заказ табака (платный)
- `order_beer_paid` - заказ пива (платный)
- `order_alcohol_paid` - заказ алкоголя
- `order_medicine_paid` - заказ фармацевтических товаров
- `order_appliances` - заказ бытовой техники
- `order_with_serial_numbers` - заказ с серийными номерами
- `order_multiple_products` - заказ с несколькими товарами

#### Utilisations Suite (Нанесения)
```
POST /v1/test/utilisations-suite
```
**6+ сценариев**:
- `utilisation_water` - нанесение воды
- `utilisation_tobacco` - нанесение табака с серией
- `utilisation_beer` - нанесение пива с серией
- `utilisation_alcohol` - нанесение алкоголя
- `utilisation_medicine` - нанесение фармацевтических товаров с серией
- `utilisation_import` - нанесение с типом ввода IMPORT

#### Aggregation Suite (Агрегация)
```
POST /v1/test/aggregations-suite
```
**4+ сценария**:
- `aggregation_simple` - простая агрегация
- `aggregation_multi_level` - многоуровневая агрегация
- `aggregation_tobacco` - агрегация табака
- `aggregation_beer` - агрегация пива

#### Full Suite (Полный цикл)
```
POST /v1/test/full-suite
```
Последовательное выполнение всех трех наборов.

#### Получение результатов
```
GET /v1/test/runs?limit=20          - История запусков тестов
GET /v1/test/cases?run_id={id}      - Детали конкретного запуска
```

## 🎯 Как использовать

### Запуск тестов через UI

1. **Откройте вкладку "🤖 Автотесты"**
2. **Выберите набор тестов**:
   - Тесты заказов
   - Тесты нанесений
   - Тесты агрегации
   - Все тесты

3. **Нажмите кнопку "▶ Запустить"**
4. **Смотрите результаты**:
   - Прогресс в реальном времени
   - Статистика (пройдено/ошибок)
   - Время выполнения
   - ID запуска для дальнейшей диагностики

5. **Посмотрите детали**: нажмите "📊 Посмотреть детали" для детального отчета

### Проверка логов в БД

```sql
-- История всех запусков
SELECT * FROM test_runs ORDER BY started_at DESC LIMIT 10;

-- Детали конкретного запуска
SELECT * FROM test_cases WHERE run_id = 1 ORDER BY created_at ASC;

-- Статистика
SELECT suite_name, status, COUNT(*) as total, 
       SUM(CASE WHEN status='PASSED' THEN 1 ELSE 0 END) as passed
FROM test_runs
GROUP BY suite_name, status;
```

- `water` - Вода и напитки
- `tobacco` - Табак
- `beer` - Пиво
- `alcohol` - Алкоголь
- `medicine` - Фармацевтические товары
- `appliances` - Бытовая техника

### GTIN тестовые коды
- Вода: `04899215122371`, `04815617815628`
- Табак: `03077972920077`
- Пиво: `04607122008417`, `04606768023249`
- Алкоголь: `04900000000061`
- Фарма: `04604680023249`
- Техника: `03700200066000`

### Важные параметры

**ReleaseMethodType**:
- `PRIMARY` - первичная маркировка (производство)
- `IMPORT` - импорт
- `CONTRACT` - контрактная маркировка

**ReleaseType**:
- `PRODUCTION` - производство
- `IMPORT` - импорт
- `TAKE_OVER` - передача прав

**CisType**:
- `UNIT` - потребительская упаковка (КИ)
- `GROUP` - групповая упаковка (КИГУ)
- `SET` - набор
